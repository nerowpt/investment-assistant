# 00 - 环境与快速开始

> 适用：Windows 本机验证 MVP-1 CLI（无需懂 Go/Python 也能按步骤操作）

---

## 你需要什么

| 项 | 版本建议 | 用途 |
|---|---|---|
| Git | 任意 | 拉代码 |
| Go | ≥ 1.22 | 编译 `inv` |
| PowerShell | Win10+ | 运行命令 |
| Python 3.10+ | H3 起 | `services/data-worker`；`pip install -e .` |

---

## 第一次运行（5 分钟）

### 1. 进入项目目录

```powershell
cd C:\Users\qs\Desktop\workspace\investment-assistant
```

### 2. 编译 CLI

```powershell
go build -o bin/inv.exe ./cmd/inv
```

成功：生成 `bin/inv.exe`，无报错。

### 3. 设置环境变量

```powershell
$env:DATA_ROOT = ".\data"
$env:IA_ACCOUNT_ID = "default"
$env:IA_CONFIG_ROOT = ".\config"
```

| 变量 | 含义 |
|---|---|
| `DATA_ROOT` | 所有运行时数据根目录（**不进 Git**） |
| `IA_ACCOUNT_ID` | 当前账户，MVP-1 默认 `default` |
| `IA_CONFIG_ROOT` | 首次初始化时复制的 YAML 模板目录 |

### 4. 验证安装

```powershell
.\bin\inv.exe version
```

**预期输出（示例）**：

```text
inv 0.1.0-h0
account_id: default
data_root:  C:\Users\qs\Desktop\workspace\investment-assistant\data
db_path:    C:\Users\qs\Desktop\workspace\investment-assistant\data\accounts\default\db\assistant.sqlite
```

## 数据存在哪

```text
data/
└── accounts/
    └── default/
        ├── state/          ← portfolio.yaml、watchlist.yaml 等（Layer A）
        ├── db/
        │   └── assistant.sqlite   ← 决策流水（Layer B）
        ├── library/        ← 研究素材文件（Layer C）
        └── reports/        ← 巡检/复盘 Markdown 报告
```

**不要**手改 `db/assistant.sqlite`（用 CLI 流程写入）。  
**可以**手改 `state/*.yaml` 做 doctor 测试，但生产路径应走 Checklist approve。

## 常用命令速查（随里程碑增加）

| 命令 | 作用 | 手册 |
|---|---|---|
| `inv version` | 版本与路径 | [H0](H0-骨架与迁移.md) |
| `inv doctor --scope library` | 检查数据库 schema | [H0](H0-骨架与迁移.md) |
| `inv doctor --scope portfolio` | 检查 portfolio 与 DB 一致 | [H1](H1-portfolio与doctor.md) |
| `inv doctor --scope watchlist` | 检查观察池与 promoted 链路 | [H1](H1-portfolio与doctor.md) |
| `inv doctor --scope all` | library + portfolio + watchlist | H1 |
| `inv library ingest` | 录入研究素材 → candidate | [H2](H2-library归纳流水线.md) |
| `inv library list` | 列出正式 library_items | H2 |
| `inv tags list` | 查看受控标签词表 | H2 |
| `inv worker health` | 探活 data-worker（自动启动） | [H3](H3-data-worker-gRPC.md) |
| `inv worker quote 600519` | 拉取行情 tier A | H3 |
| `inv checklist draft --type buy …` | 创建建仓决策表单 | [01 流程](01-操作流程总览.md) · [H4](H4-checklist与M7.md) |
| `inv checklist submit / approve` | 提交 M7 / 落库记账 | [01 流程](01-操作流程总览.md) · [H5](H5-checklist-approve.md) |
| `inv checklist reject` | 作废 draft/submitted | [H4](H4-checklist与M7.md) §接口 2b |

全局 flag：

| flag | 说明 |
|---|---|
| `--account <id>` | 切换 account（覆盖 `IA_ACCOUNT_ID`） |

## 重置测试环境

```powershell
Remove-Item -Recurse -Force .\data\accounts\default -ErrorAction SilentlyContinue
.\bin\inv.exe doctor --scope library
```

会重新创建目录、跑 migration、从 `config/*.example.yaml` 复制 state 模板。
