## 接口 1：`inv version`

### 签名

```text
inv version [--account <id>]
```

### 参数

| 参数 | 位置 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|---|
| `--account` | 全局 flag | 否 | string | `IA_ACCOUNT_ID` 或 `default` | 指定 account |

### 成功输出

```text
inv 0.1.0-h0
account_id: default
data_root:  C:\Users\qs\Desktop\workspace\investment-assistant\data
db_path:    C:\Users\qs\Desktop\workspace\investment-assistant\data\accounts\default\db\assistant.sqlite
```

### 失败输出

无典型失败场景（纯打印路径）。

### 退出码

| 码 | 场景 |
|---|---|
| 0 | 成功 |

### 手动验证

```powershell
.\bin\inv.exe version
.\bin\inv.exe version --account default
```

## 接口 2：`inv doctor --scope library`

### 签名

```text
inv doctor [--scope library|portfolio|all]
```

H0 验收 scope=`library`。

### 行为说明

1. 创建 `data/accounts/{id}/` 下必要目录
2. 若 state 文件不存在，从 `config/*.example.yaml` 复制
3. 打开/创建 `assistant.sqlite`，执行 `001_initial.up.sql` 迁移
4. 检查 MVP-1 核心表是否存在

### 参数

| 参数 | 位置 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|---|
| `--scope` | flag | 否 | string | `library` | H0 用 `library` |

### 成功输出

```text
doctor OK (scope=library, schema_version=1)
```

### 副作用（文件系统）

| 路径 | 变化 |
|---|---|
| `data/accounts/default/db/assistant.sqlite` | 新建或打开 |
| `data/accounts/default/state/portfolio.yaml` | 若不存在则从 example 复制 |
| `data/accounts/default/state/watchlist.yaml` | 同上 |
| 其他 `state/*.yaml` | 同上 |

### 失败输出示例

**场景：migration SQL 损坏**

```text
Error: 执行迁移: ...
```

### 退出码

| 码 | 场景 |
|---|---|
| 0 | schema 完整 |
| 1 | 迁移失败 / 缺表 |

### 手动验证

```powershell
# 干净环境
Remove-Item -Recurse -Force .\data\accounts\default -ErrorAction SilentlyContinue

.\bin\inv.exe doctor --scope library
# 预期：doctor OK (scope=library, schema_version=1)

# 确认文件存在
Test-Path .\data\accounts\default\db\assistant.sqlite
Test-Path .\data\accounts\default\state\portfolio.yaml
```

### 自动化验证

```powershell
go test ./internal/core/store/sqlstore/... -count=1
go test ./internal/core/store/yamlstore/... -count=1
```
