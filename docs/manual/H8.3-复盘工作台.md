## 一、目标

对已关闭 lot 做**单笔归因复盘**：从选股看板「已卖出」进入，查看 lot 盈亏与卖出对照，填写 `review` checklist 并 approve 写入 `review_reports`。

**本阶段不做**：完整季度复盘向导、自动错误模式扫描、emotion_retrospect 30/90 天调度。

### 2.2 复盘向导（`type=review&lot_id=…`）

- 预填：`review_type=lot_attribution`、`target_lot_id`、`period_start/end`
- 只读对照区：建仓摘要、卖出时的 lesson / thesis_result
- 用户填写：结果四分类、`confirmed_patterns`（至少 1 条）

---

## 三、API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/review/workbench?code=` | 标的下全部已关闭 lot 列表 |
| GET | `/api/review/lot-context?code=&lot_id=` | 单笔 lot 复盘上下文 + 向导预填 |
| GET | `/api/checklist/schema?type=review` | 复盘表单 schema |
| POST | `/api/checklist` → submit → approve | 与通用向导相同 |

**workbench 字段**：`closed_lots[]` 含 `lot_id`、`holding_days`、`realized_return_pct`、`realized_pnl_amount`、`reviewed`、`review_report_id`。

**lot-context 字段**：`lot`、`sell_context`（卖出 journal 摘要）、`prefill`（扁平预填）。

## 五、验收

1. 完成一笔卖出 approve（lot 状态 `closed`）
2. 选股看板 → **已卖出** → 点 **复盘**
3. 工作台显示 lot 卡片与盈亏
4. 点 **写复盘** → 向导预填 lot 区间与对照信息
5. 填写 `confirmed_patterns` → submit → approve
6. 验证：

```powershell
sqlite3 data\accounts\default\db\assistant.sqlite "SELECT id, review_type, period_start, period_end FROM review_reports ORDER BY created_at DESC LIMIT 3;"
```

**预期**：`review_type=lot_attribution`；`user_judgment_json` 含 `target_lot_id` 与非空 `confirmed_patterns`。
