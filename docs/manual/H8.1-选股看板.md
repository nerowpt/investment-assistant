# H8.1 - 选股看板 + 从观察区买入

> 状态：✅ 实现中  
> 依赖：[H8-web-api与前端](H8-web-api与前端.md)、[02 §六 选股与观察池](../02-核心场景与功能边界.md)

## 一、目标

补全生命周期「选股」环节：用**聚合看板**展示五类分区，并从**观察区 / 研究区**一键进入买入向导，自动带入 L1 与观察假设。

**本阶段不做**：研究页按需拉取（H8.2）、复盘工作台（H8.3）。

```
└─────────────────────────────────────────┘
```

**分区定义**

| Tab id | 标题 | 数据来源 | 卡片主操作 |
|--------|------|----------|------------|
| `watching` | 观察区 | `watchlist` watching | **我要买入**、查看记录 |
| `researching` | 研究区 | 有 L1、未 watch、未持仓 | **我要买入** |
| `holding` | 已建仓 | `portfolio` holding | 加仓、巡检、卖出 |
| `closed` | 已卖出 | `portfolio` closed | 查看记录（复盘 H8.3） |
| `swing` | 波段/做T | `position_type=swing` | 同持仓/已卖出 |

### 2.3 买入向导（改造入口）

从观察区点击「我要买入」：

```
/pages/wizard/index?type=buy&code=000858&name=五粮液
  &from=watchlist&watch_id=w_20260608_001
```

向导加载后调用 `GET /api/pool/buy-context`，预填：

- `source_entry` = `from_watchlist`
- `watchlist_origin_id`
- `related_library_ids`（该 code 全部 active L1）
- `buy_reason_summary` ← `watch_reason`
- `investment_thesis` ← `hypothesis`（用户可改）

## 三、HTTP API 字段清单

### 3.1 `GET /api/pool`

**Query**

| 参数 | 类型 | 说明 |
|------|------|------|
| `zone` | string | 可选，过滤单分区：`watching` / `researching` / `holding` / `closed` / `swing` |

**Response `data`**

```json
{
  "zones": [
    {
      "id": "watching",
      "title": "观察区",
      "description": "待验证假设，未建仓",
      "count": 3,
      "items": [ { "...PoolItem" } ]
    }
  ],
  "updated_at": "2026-06-08T12:00:00+08:00"
}
```

**`PoolItem`**

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | string | 标的代码 |
| `name` | string | 名称 |
| `zone` | string | 所属分区 id |
| `ref_id` | string? | 观察项 `w_*`；持仓可为空 |
| `summary` | string? | 一行摘要（hypothesis / thesis / watch_reason） |
| `library_count` | int | 关联 active L1 条数 |
| `review_date` | string? | 观察区下次复查 YYYY-MM-DD |
| `position_pct` | string? | 持仓仓位 % |
| `position_type` | string? | `core` / `swing` |
| `state` | string? | `watching` / `holding` / `closed` |
| `entry_date` | string? | 建仓日 |
| `closed_at` | string? | 清仓日 |
| `pool_tags` | string[]? | 预留；H8.1 仅 swing 由 `position_type` 推导 |
| `actions` | string[] | 前端可用操作：`buy` `add` `inspect` `sell` `records` |

### 3.2 `GET /api/pool/buy-context`

**Query**

| 参数 | 必填 | 说明 |
|------|------|------|
| `code` | 是 | 标的代码 |
| `from` | 否 | `watchlist` / `research`；默认 `research` |
| `watch_id` | 条件 | `from=watchlist` 时建议传 `w_*` |

**Response `data`**

```json
{
  "code": "000858",
  "name": "五粮液",
  "from": "watchlist",
  "watch_id": "w_20260608_001",
  "prefill": {
    "source_entry": "from_watchlist",
    "watchlist_origin_id": "w_20260608_001",
    "related_library_ids": ["lib_20260609_001"],
    "buy_reason_summary": "…",
    "investment_thesis": "…"
  },
  "library_items": [
    { "id": "lib_…", "title": "…", "tier": "B", "summary": "…" }
  ]
}
```
