---

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/research/{code}` | 研究档案（分区、L1、数据包定义、worker 状态） |
| POST | `/api/research/{code}/fetch` | body `{pack}` 拉取事实数据 |
| POST | `/api/research/{code}/library` | body `{title,text,tier?}` 纳入 L1 |

**pack 枚举**：`quote` | `company_valuation` | `sector_valuation` | `volume` | `market_benchmark` | `news`

**名称补全**：研究档案与选股看板在仅有 L1、无 watchlist/portfolio 名称时，通过行情接口补全公司简称（`ResolveStockName` / `EnrichPoolNames`）。

---

## 验收

1. 输入 `000858` → 标题与卡片显示「五粮液」而非重复代码
2. 看到 6 个数据包（含板块估值、成交量）
3. 点「拉取」成交量 → 展示近日 vs 60 日均量及缩量/放量标签
4. 点「纳入 L1」→ 研究区/买入向导可关联该素材
5. worker 未启动时页面提示，不崩溃

**启动 worker**：首次拉取时 Go 侧会自动 `EnsureWorker`；若失败请检查 Python 环境与网络。

---

## 边界

- 板块历史估值分位：MVP-1 公司估值包分位为 0，H8.2+ 再补
- 新闻 tier 默认 C，行情/估值 tier A
- AI 不写结论；入库内容为格式化事实文本
