# 知识基线 01 - 投资理念与风格

> 用户的投资底层世界观。这是产品的"灵魂"，决定所有功能的取舍。
> 来源：2026-05-12 起的多轮深度对话沉淀。

---

## 一、核心风格

| 维度 | 立场 |
|---|---|
| 时间尺度 | **长线为主**（主仓 1-3 年+），**部分仓位做热点轮动**（波段 1 个月-1 年） |
| 投资哲学 | 价值投资 + 板块轮动 + 估值回归 + AI 时代的高赔率博弈 |
| 反对的做法 | 高频交易、技术指标短炒、追涨杀跌 |
| 支持的做法 | 底部建仓、持有低估值板块等待均值回归、产业升级与全球化的长期叙事 |
| 风格演进 | 已经从"板块轮动"思维 → "产业进化"思维 → 正在向 **"资本回报率"** 思维过渡 |

---

## 二、对散户优势的核心信念

> 散户最大的优势是**没有业绩考核压力**，可以长期持有低估值板块等待均值回归。

但用户已经清醒地识别到这个信念的"半真半假"：
- ✅ 真：散户拥有"无限期持有权"，可以避开机构季度排名压力
- ❌ 致命误区：**把"等"当成战略**，而忽略机会成本和资本效率

---

## 三、从"板块思维"到"资本回报率思维"的进化

### 进化路径（已经发生）

```
价格投资者（早期）
    ↓ 跌多了一定回去
板块轮动投资者（早期-中期）
    ↓ 中国一定能跑出世界级公司
产业升级投资者（中期）
    ↓ 关键不是产业能不能起来，而是它是不是那个赢家
公司护城河投资者（当前）
    ↓ ROE × 可持续时间才是最终决定
资本回报率投资者（目标方向）
```

### 当前世界观的关键判断

1. **均值回归会失效**：当行业 ROE 永久下移（如医疗器械、传统券商），"低估"不等于"价值在"
2. **时代的更替**：有的板块"主人变了"，狗等再久也找不回来（永辉、绝味就是案例）
3. **真正的长期投资**：不是等均值回归，而是找到那个未来会**重新定义"均值"**的公司
4. **资本回报率公式**：长期股价 ≈ ROE × 可持续时间（不是 PE / PB / 跌得久）

## 四、关注的核心维度（决定 AI 巡检该看什么）

| 优先级 | 维度 | 含义 |
|---|---|---|
| **P0** | **行业 ROE 是否持续恶化** | 如果 ROE 中枢永久下移，再低估也无意义 |
| **P0** | **公司自由现金流是否恶化** | 真造血 vs 纸面富贵 |
| **P0** | **市场份额是否下降** | 竞争位置的客观证据 |
| **P0** | **核心叙事是否被时代改变** | 商业模式永久性恶化 vs 周期性下行 |
| P1 | 海外收入占比 | 全球化能力 |
| P1 | 创新能力 / 研发转化效率 | 真创新 vs 营销驱动 |
| P1 | 估值分位（PE / PB） | 安全边际 |
| P1 | 机构持仓变化 | 资金面信号 |
| P2 | 产业生命周期 | 成长 / 成熟 / 衰退 |
| P2 | 政策与监管环境 | 制度型行业的关键变量 |

## 五、对 AI 协作者的明确要求

### ✅ 用户希望 AI 做的

1. **基于最新联网数据**做分析（不要凭训练记忆答）
2. **区分事实 / 推理 / 结论**三件事，标注每个判断的可信度
3. **指出认知陷阱**（用户已经识别但仍可能再陷的）
4. **给出场景化测算**（保守 / 中性 / 乐观）
5. **关注"逻辑是否破坏"而非"股价涨跌"**
6. **直接说人话**，不要"黎明前的黑暗"那种修辞包装

### ❌ 用户明确反对的

1. **过度共情型叙事**："你说得对，确实只是情绪问题" — 这是最危险的回应模式
2. **真数据 + 强叙事推演 + 未验证结论**的组合（用户已多次警告）
3. **凭训练记忆给数据**（必须联网）
4. **用"长期"模糊"资本效率低"**
5. **"再等等"、"耐心"** 之类的鼓励词，没有数据支撑就是麻醉剂
6. 编造研报、估值数据、产品节奏、市场传闻

## 六、风险偏好

| 类别 | 用户立场 |
|---|---|
| 单标的最大持仓 | 没有硬性上限，但**对单产品依赖型公司**（如完美异环、微创机器人）会主动控制 |
| 波动容忍度 | **能承受 30-50% 浮亏**，前提是逻辑未破坏 |
| 止损线 | **不机械化止损**。止损条件是"逻辑破坏"，不是"价格下跌" |
| 止盈策略 | 主仓基于"目标价 + 估值修复"，热点仓基于"题材熄火 / 量价异常" |
