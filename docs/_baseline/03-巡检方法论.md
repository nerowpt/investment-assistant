## 一、核心原则

### "逻辑破坏" ≠ "股价下跌"

**任何巡检的目标不是判断"涨没涨"，而是判断：**

> 当前股价的疲弱，是属于哪一种？
>
> 1. **正常波动** — 不需要任何动作
> 2. **情绪压制** — 等待修复，可加仓
> 3. **周期低谷** — 周期型行业的常态，看 ROE 是否在回升轨道
> 4. **逻辑真正恶化** — 必须减仓或清仓

## 二、四层巡检模型（自上而下）

### 第 1 层：宏观流动性（Beta）

**问题**：市场愿不愿意给这个板块"钱"？

| 指标 | 数据来源 | 触发警报阈值 |
|---|---|---|
| A 股日成交额 | 东财 / AKShare | 持续 < 1 万亿 / 跌破 1.5 万亿持续 2 周 |
| 两融余额 | 东财融资融券 | 月环比下降 > 10% / 连续 2 周净流出 |
| 北向资金 | 东财 / 港交所 | 月度净流出 > 500 亿 |
| 十年国债收益率 | Wind / AKShare | 急升 > 30bp 在 1 个月内 |
| 宽基 ETF 资金流 | Choice / AKShare | 持续净赎回 > 10 个交易日 |

**关键警示信号（牛市后半段背离）**：
- 两融历史新高 + 宽基 ETF 净赎回 → 配置盘减仓 + 散户加杠杆 = 风险
- 数据出处：2026-05-12 巡检中识别（两融 2.78 万亿创历史新高 + 宽基 ETF 18 个交易日净赎回 2625 亿）

### 第 2 层：行业逻辑（行业 Alpha）

**问题**：行业 ROE 中枢在改善还是恶化？

#### 券商行业核心指标

| 指标 | 健康线 | 数据来源 |
|---|---|---|
| 行业年化加权 ROE | > 7% 健康 / > 10% 强势 | 上市券商一致预期 |
| 头部四大券商 ROE | > 12% 牛市信号 | 中信、华泰、广发、中金合计 |
| 经纪业务收入增速 | > 20% 健康 | 行业月度数据 |
| 投行业务增速 | > 10% 健康 | 注册制环境下要求 |
| 头部券商 PB | < 1.2 倍 = 极度低估 | Wind / 同花顺 |

#### 医疗器械行业核心指标

| 指标 | 健康线 | 数据来源 |
|---|---|---|
| 板块整体 Q1/H1/全年营收增速 | 转正即拐点 | 上市公司财报 |
| 板块整体净利润增速 | 拐点信号：从负转正 | 上市公司财报 |
| 海外收入占比（行业整体） | > 30% 健康 | 公司年报披露 |
| 集采进度 | 出清完成度 | 国家医保局公告 |
| 公募基金持仓变化 | 环比回升即资金信号 | 季报披露 |

#### 游戏行业核心指标

| 指标 | 健康线 | 数据来源 |
|---|---|---|
| 中国游戏市场季度流水 | 同比 +5% 以上健康 | 游戏工委 / 伽马数据 |
| 海外手游收入增速 | > 20% 健康 | Sensor Tower |
| 版号发放节奏 | 每月 70+ 款健康 | 国家新闻出版署 |
| 头部公司分化度 | 越分化越要选公司 | 自定义指标 |

#### 消费行业核心指标

| 指标 | 健康线 | 数据来源 |

| CPI（消费意愿） | > 1% 健康 | 国家统计局 |
| 量贩零食店扩张速度 | 对传统消费的冲击度 | 行业调研 |

#### 创新药行业核心指标

| 指标 | 健康线 | 数据来源 |
|---|---|---|

### 第 3 层：公司护城河（核心 Alpha）

**问题**：这家公司在变好还是变坏？

| 必看指标（P0） | 含义 |
|---|---|
| **ROE** | 真盈利能力（不是 PE） |
| **自由现金流** | 真造血（不是利润） |
| **市场份额** | 竞争位置的客观证据 |
| **海外收入** | 全球竞争力 |
| **研发转化效率** | 真创新（研发费用 / 上市新品） |
| **资产负债结构** | 是否危险（如微创案例） |

| 重要指标（P1） | 含义 |
|---|---|
| 管理层资本配置能力 | 钱花得对不对 |
| 销售费用率变化 | AI 提效 / 内卷加剧的信号 |
| 经营性现金流 / 净利润 | 利润质量（> 1 健康） |
| 客户集中度 | 议价能力 |
| 应收账款周转 | 渠道健康度 |

#### 关键的"利润质量"判断

警惕这些"看起来好但有问题"的利润：
- ⚠️ 净利大涨但扣非小涨 → 一次性收益
- ⚠️ 利润涨但经营性现金流跌 → 利润可能虚胖（三七 Q1 案例：净利+59%、扣非+13.7%、现金流-37%）
- ⚠️ 净利率提升但市场份额下降 → 在做减法保利润，长期堪忧
- ⚠️ 净利依赖资产处置 → 不可持续（微创 2025 案例）

## 三、巡检的「四象限分类」（输出形式）

每次巡检对每个标的输出一个分类：

| 象限 | 判断标准 | 行动建议 |
|---|---|---|
| **✅ 低估值且逻辑还在** | 行业 ROE 改善 + 公司护城河完好 + 估值低分位 | **坚定持有，可加仓** |
| **⚠️ 等待风格切换** | 公司基本面 OK，但市场审美在别处 | **拿住，不加不减，监控资金面** |
| **🔄 周期低谷 / 逻辑反转中** | 周期性行业进入磨底，或公司转型初见成效 | **保留观察，不冲动减仓** |
| **❌ 价值陷阱 / 逻辑已破坏** | 行业 ROE 永久下移 / 商业模式被时代改变 / 现金流持续恶化 | **借反弹退出** |

## 四、巡检的「四维度判断」（必填字段）

每次巡检报告必须明确回答：

```yaml
inspection_summary:
  stock_code: 002624
  date: 2026-05-15
  
  # 必填四个维度
  industry_roe_trend: improving | stable | deteriorating
  free_cash_flow_trend: improving | stable | deteriorating
  market_share_trend: gaining | stable | losing
  core_narrative_status: intact | shifting | broken
  
  # 综合判断
  classification: low_valuation_logic_intact | wait_for_style_switch | cycle_bottom | value_trap
  
  # 关键信号
  positive_signals: [...]
  negative_signals: [...]
  watch_signals: [...]
  
  # 行动建议
  action: hold | add | reduce | exit
  confidence: low | medium | high
  
  # 反转条件
  reversal_signals: [...]  # 什么发生时改变判断
```

## 五、巡检触发时机

### 定时触发（系统自动）

| 触发时机 | 巡检对象 | 深度 |
|---|---|---|
| **每月 1 日** | 全部持仓 | 浅度（数据更新 + 市场行为变化） |
| **季报后 7 天** | 全部持仓 | 深度（财报全维度对比） |
| **半年报 / 年报后 14 天** | 全部持仓 | 极深度（含管理层评价、资本配置） |
| **重要政策出台** | 受影响板块 | 中度 |

### 事件触发（系统监控）

| 事件 | 巡检对象 |
|---|---|
| 标的发布业绩预告 / 预增 / 预减 | 该标的 |
| 标的高管增减持 | 该标的 |
| 标的发生重大资本运作（并购、定增、回购） | 该标的 |
| 行业出现重大政策（如医保集采、游戏版号） | 板块 |
| 主要竞争对手发生重大变化 | 该标的（横向对比） |

### 手动触发

```bash
inv inspect --target=all
inv inspect --target=002624
inv inspect --sector=securities
inv inspect --since=2026-04-01  # 自上次巡检后的增量
```
