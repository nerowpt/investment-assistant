# 个人投资分析助手 (Investment Assistant)

> 一个供个人长线投资者使用的、以 AI 为深度分析协作者的投资决策辅助系统。
>
> **核心定位**：给 LLM 用的投资分析工具集（MCP Server）+ 个人持仓中枢 + 多端轻量 UI

---

## 🤖 新对话开始时必读（AI Onboarding）

> ⚠️ **任何在本项目中协作的 AI（Cursor / Claude Desktop / 其他 LLM）必须先按本节加载上下文，再开始工作。**
>
> 否则会丢失大量已经达成的决策与方法论，导致重复讨论或方向偏差。

### 加载顺序（5 分钟读完）

1. **本文档（README.md）** — 了解项目阶段与协作规则
2. **`docs/_baseline/01-投资理念与风格.md`** — 用户的投资底层世界观
3. **`docs/_baseline/02-当前持仓与个人逻辑.md`** — 用户的具体持仓和买入理由
4. **`docs/_baseline/03-巡检方法论.md`** — 巡检的"四层模型 + 四象限 + 四维度"
5. **`docs/_baseline/04-历次巡检结论基线.md`** — 此前已完成巡检的结论（用于对比）
6. **`docs/_baseline/05-认知陷阱与AI协作边界.md`** — ⚠️ 必读，AI 严格遵守的边界
7. **`docs/00-讨论历史与决策日志.md`** — 所有已做的决策（避免重复讨论）
8. **当前所在阶段的文档** — 见下方"当前阶段"

### 协作时的硬性边界（来自 baseline-05）

- ❌ 禁止"真数据 + 强叙事推演 + 未验证结论"的混合体
- ❌ 禁止过度共情型叙事（"再等等"、"黎明前的黑暗"等麻醉话术）
- ❌ 禁止凭训练记忆给数据（必须联网）
- ❌ 禁止用"长期"模糊"资本效率"
- ✅ 所有判断必须区分 **📊 事实 / 🧠 推理 / ⚖️ 结论**，并标注置信度
- ✅ 不主动给"买/卖"指令，决策权 100% 在用户

## 🎯 产品快速理解（30 秒版本）

**用户**：1 人，长线为主 + 部分仓位做热点。已识别"AI 财经分析的高级幻觉"陷阱，对协作者要求高。

**痛点**：
1. 长线被低估值板块"等"了多年，错过科技牛
2. 无法持续做深度逻辑巡检（信息量大、时间不够）
3. 容易陷入"用长期掩盖错误"
4. 短线热点信息抓不及时

**MVP（已确认）**：「持仓管理 + 逻辑巡检 + 热点扫描」三模块（长短双引擎）

**技术栈（已确认）**：Python（数据/分析）+ Go（后端 API + MCP Server + 调度器）

**关键架构决策**：通过 MCP 协议把后端能力暴露给 LLM。本质是"给 LLM 用的工具集"而非"套了 LLM 的应用"——不重复造轮子，复用 Cursor / Claude Desktop 订阅。

## 起源

本项目源于 2026-05-12 起的多轮关于"长期价值投资 vs 板块轮动 vs 个股选择"的深度对话。

讨论的初始上下文：
- **持仓**：券商（光大/中金/中国银河）、医疗器械（微创/乐普）、游戏（三七/完美）、消费（良品/绝味/永辉）、创新药（复星/健康元）
- **风格**：长线价值投资为主 + 部分仓位博弈板块轮动
- **痛点**：六年长线持仓被 AI/科技板块跑输，需要系统化的逻辑巡检机制

完整的对话历史与判断已沉淀到 `docs/_baseline/` 5 份文档中。
