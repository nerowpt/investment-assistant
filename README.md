# 个人投资分析助手 (Investment Assistant)

> 一个把投资决策流程产品化、把投资行为数据化、把投资经验个人化、把市场叙事可观察化的「执行规范、复盘与个人知识积累系统」。
>
> **核心定位**: 散户的投资飞行日志 + 个人投资知识资产 — Checklist 引擎 + 决策日志 + 规则化监控(含叙事信号包) + 复盘助手(含错过模式扫描) + 风险护栏 + 持仓中枢 + 研究素材库。**AI 是数据秘书与复盘陪练,不是决策者。叙事信号包是反偏见工具,不是水晶球。**

### 协作时的硬性边界(来自 baseline-05 + v0.3 升级)

#### 来自 baseline-05 的边界(协作礼仪)

- ❌ 禁止"真数据 + 强叙事推演 + 未验证结论"的混合体
- ❌ 禁止过度共情型叙事("再等等"、"黎明前的黑暗"等麻醉话术)
- ❌ 禁止凭训练记忆给数据(必须联网)
- ❌ 禁止用"长期"模糊"资本效率"
- ✅ 所有信息必须区分 **📊 事实 / 🧠 推理 / ⚖️ 结论**,并标注置信度

#### v0.3 新增的架构级硬约束(产品级,不可绕过)

> ⚠️ 这些不是"建议"或"礼仪",是 v0.3 起把 AI 严格降级为"数据秘书"的产品级硬约束。

- ❌ **AI 永远不写结论性字段**: 不写分类(四象限)、不写行动建议、不写置信度
- ❌ AI 不评估"哪只标的会涨"、"弹性多大"、"是否值得买"
- ❌ AI 不主动生成"完整的巡检判断报告",只填事实部分
- ✅ AI 的允许动作: 取数据、汇总信息、引用原文、按模板格式化、检索历史 Journal、**从 L1 研究素材库检索素材(v0.4)**
- ✅ 决策权与**结论权** 100% 在用户(v0.2 只说决策权,v0.3 进一步收紧"结论权")
- ✅ AI 全部不可用时,产品依然能用 CLI 完成 Checklist + Journal + 监控 + 复盘 + L1 录入

#### v0.4 新增的架构级硬约束

- ❌ **AI 不给"合理价格"或"应该买入价"结论**: 估值辅助子工具(在 M2 中)只给客观数据(PE 分位/同业对比/PE 锚定测算),target_price 必须用户填
- ❌ **不做日级短线热点推荐**: M4 监控只发"市场状态画像 + 板块异动信号", M6 候选池只做"事件驱动 + 信息汇总",**不做"今天买什么"类输出**
- ✅ **信息源可信度分级 S/A/B/C/D**: 所有数据带 tier 标签, C/D 级作为主要依据时系统弹确认
- ✅ **决策快照"冻结即不变"**: Journal 中的 data_snapshot 一旦写入只读, L1 后续版本更新不回填覆盖
- ✅ **风险护栏作为决策拦截层**: 触发仓位规则/个人禁区时, Checklist 提交会被拦截,必须写"例外说明",永久记入 Journal

#### v0.5 新增的架构级硬约束(叙事场景)

- ❌ **AI 不判断叙事周期阶段**: 叙事信号包只呈现六维客观信号,`narrative_stage` 必须用户填
- ❌ **AI 不编造叙事故事链条**: 叙事场景幻觉风险最高,禁止"产业链推演型"结论输出
- ✅ **叙事信号包附声明**: 所有叙事相关报告必须标注「反偏见工具,非水晶球」
- ✅ **建仓强拦截**: 标的有未过期的叙事信号包时,建仓 Checklist 必须先完成 `narrative_stage_assessment`

## 🎯 产品快速理解(30 秒版本 - v0.5)

**用户**: 1 人,长线为主 + 部分仓位做热点。6+ 年实盘经验,**判断力本身不缺**,缺的是把判断力**纪律化、记录化、可复盘化、风险可控、研究素材资产化、叙事拐点可观察化**的工具。已识别"AI 财经分析的高级幻觉"陷阱,对协作者要求高。

**真实痛点(v0.5 完整识别)**:
1. **执行不规范**: 买卖凭直觉,事后想不起当时判断依据
2. **复盘不彻底**: 账户盈亏知道,但说不清是哪个环节的错
3. **风险管理零散**: 没有仓位规则、个人禁区、回撤护栏等明确约束
4. **研究素材未沉淀**: 看过的资料、大牛观点散落各处,3 个月后找不到
5. **错过新叙事周期**: 长线在低估值板块"等"多年,错过科技牛 — 「用长期掩盖错误」+「无法识别产业新叙事早期信号」双重失效(v0.5 显式拆分)
6. **AI 不可靠**: 现有大模型在金融领域幻觉严重,难以即时验证

**产品定位(v0.5)**: 散户的投资飞行日志 + 个人投资知识资产 + 叙事观察镜。AI 是数据秘书,不是决策者。**叙事信号包是反偏见工具,不是水晶球。**

**MVP(v0.5: L1 + 7 业务模块, M4/M5 内嵌叙事子模块, 拆 MVP-1/MVP-2)**:

🆕 **L1 研究素材库**: 自动入库 + 手动录入 + 检索 — 叙事历史可比案例的最大消费者之一

业务模块层:
1. M1 持仓状态机(含 watching 观察池)
2. M2 Checklist(估值辅助 + emotion_tag + **叙事阶段强拦截**)
3. M3 决策日志(快照冻结 + L1 引用)
4. M4 监控(个股/板块/市场状态 + **★叙事信号包 [MVP-2]**)
5. M5 复盘(错误模式/策略画像 + **★叙事错过模式扫描 [MVP-2]**)
6. M6 候选池(事件驱动,周/月级,不下结论)
7. M7 风险护栏(仓位规则 + 个人禁区)

**关键架构决策**:
- v0.3: AI 不写结论性字段,流程+记录+复盘为骨架
- v0.4: L1 + M7 + 观察池 + emotion + 信息源分级 + 快照冻结
- v0.5: 叙事识别嵌入 M4/M5,六维信号 + 用户填阶段 + AI 禁编故事
- AI 全部不可用时,产品依然完整可用

**总工期**: MVP-1 (13-17 周) + MVP-2 (**15-21 周**) = 约 **7-9 个月**业余时间

## 起源

本项目源于 2026-05-12 起的多轮关于"长期价值投资 vs 板块轮动 vs 个股选择"的深度对话。

讨论的初始上下文：
- **持仓**：券商（光大/中金/中国银河）、医疗器械（微创/乐普）、游戏（三七/完美）、消费（良品/绝味/永辉）、创新药（复星/健康元）
- **风格**：长线价值投资为主 + 部分仓位博弈板块轮动
- **痛点**：六年长线持仓被 AI/科技板块跑输，需要系统化的逻辑巡检机制

完整的对话历史与判断已沉淀到 `docs/_baseline/` 5 份文档中。
